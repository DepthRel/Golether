## 1. Что делает сервер

Golether — программа для совместного просмотра видео. Обычно ведущий и участники сидят за домашними роутерами без
открытых портов («серый» IP, NAT провайдера), и напрямую друг до друга не достают. Сервер рукопожатий их знакомит:

- ведущий держит на сервере «комнату» своего сеанса;
- участник по ссылке-приглашению просит сервер свести его с ведущим;
- сервер сообщает обоим внешние адреса друг друга, и они сами пробивают **прямое** соединение через свои роутеры;
- по тому же порту, но по UDP, сервер отвечает на STUN-запросы: так напрямую соединяются и камеры с голосом.

Через сервер **не идут** фильм, синхронизация, чат, камеры и голос — только короткие служебные сообщения при
подключении. Нагрузка минимальная; один сервер обслуживает сотни одновременных сеансов.

## 2. Что нужно

| | |
|---|---|
| Сеть | белый (публичный) IPv4-адрес у машины или у роутера, на котором можно пробросить порт |
| Порты | **TCP 47900** и **UDP 47900** снаружи (номер настраивается); порт 47980 — только локально |
| Windows | Windows 10 / Windows Server 2016 или новее, x64 или arm64 |
| Linux | x64 или arm64 с glibc (Debian 11+, Ubuntu 20.04+, RHEL/Alma/Rocky 8+ и подобные) и systemd для работы службой |
| macOS | macOS 14 или новее, Apple Silicon или Intel |
| Ресурсы | около 100 МБ на диске и 60–100 МБ памяти |

.NET устанавливать не нужно: он уже внутри пакета.

## 3. Состав пакета

| Файл | Назначение |
|---|---|
| `golether-server` (`golether-server.exe` на Windows) | запуск сервера — единственный файл в корне; одна программа работает и в консоли, и службой |
| `bin/` | сама программа, среда .NET и библиотеки; туда заглядывать не нужно |
| `config/appsettings.json` | настройки: адрес, порт, лимиты (см. [раздел 5](#5-настройки)) |
| `docs/ADMIN-GUIDE.md` | это руководство |
| `docs/README.txt` | краткая памятка к конкретному пакету |
| `service/install-service.sh` | Linux и macOS: установка, обновление и удаление службы |
| `service/golether-server.service` | Linux: юнит systemd (его ставит `install-service.sh`) |
| `service/org.golether.server.plist` | macOS: задание launchd (его ставит `install-service.sh`) |

```
GoletherServer/
  golether-server(.exe)
  bin/        программа и библиотеки
  config/     appsettings.json
  docs/       ADMIN-GUIDE.md, README.txt
  service/    только Linux и macOS
```

Установщик Windows раскладывает файлы так же; его собственные файлы удаления лежат в папке `uninstall`.

Для Windows есть ещё отдельный установщик `GoletherServer-<версия>-setup.exe`.

## 4. Установка

Выберите способ для своей системы. Во всех случаях после установки нужно открыть порты
([раздел 6](#6-роутер-и-брандмауэр)).

### Windows — установщик (рекомендуется)

Запустите `GoletherServer-<версия>-setup.exe` (нужны права администратора). Установщик:

- ставит сервер в `C:\Program Files\Golether Server`;
- регистрирует службу **GoletherServer** («Golether rendezvous server»): запуск вместе с компьютером, перезапуск
  через 5 секунд после сбоя;
- добавляет правило брандмауэра Windows для программы (TCP и UDP, любой порт);
- добавляет в меню «Пуск → Golether Server» ярлыки на настройки, это руководство и страницу состояния.

Службу и правило брандмауэра можно отключить галочками на шаге «Дополнительные задачи».

### Windows — из zip-архива

Распакуйте архив, например в `C:\GoletherServer`, и запустите `golether-server.exe` из корня папки — сервер работает, пока открыто
окно консоли. Чтобы он работал службой, выполните в PowerShell **от администратора** из корня папки сервера:

```powershell
$exe = Join-Path (Get-Location) 'golether-server.exe'
New-Service -Name GoletherServer -DisplayName 'Golether rendezvous server' -BinaryPathName "`"$exe`"" -StartupType Automatic
sc.exe failure GoletherServer reset= 86400 actions= restart/5000/restart/5000/restart/60000
New-NetFirewallRule -DisplayName 'Golether rendezvous server' -Direction Inbound -Program $exe -Action Allow
Start-Service GoletherServer
```

Папку после этого не переносите: служба запускает программу по полному пути.

### Linux — служба systemd

```bash
tar -xzf GoletherServer-<версия>-linux-x64.tar.gz
cd GoletherServer
sudo ./service/install-service.sh
```

Скрипт копирует сервер в `/opt/golether-server`, ставит юнит `golether-server.service`, включает автозапуск и
запускает службу. Если включён `ufw`, скрипт сам открывает порт из настроек; для `firewalld` и `iptables` см.
[раздел 6](#6-роутер-и-брандмауэр). Служба работает от временного непривилегированного пользователя (`DynamicUser`)
с защитой файловой системы — права root серверу не нужны.

Без службы: `./golether-server` в корне папки пакета (остановка — `Ctrl+C`).

### macOS — служба launchd

```bash
tar -xzf GoletherServer-<версия>-osx-arm64.tar.gz     # osx-x64 для Intel
cd GoletherServer
sudo ./service/install-service.sh
```

Скрипт копирует сервер в `/usr/local/golether-server`, снимает карантин загруженных файлов, подписывает программу
локальной подписью (она нужна macOS на Apple Silicon), ставит задание `/Library/LaunchDaemons/org.golether.server.plist`
и запускает его. Сервер работает от пользователя `nobody` и перезапускается после сбоя.

Без службы: `./golether-server` в корне папки пакета. Если macOS пишет, что программу нельзя открыть, выполните там
`xattr -dr com.apple.quarantine .` и `codesign --force --sign - golether-server bin/golether-server`. При первом запуске системный
брандмауэр macOS (если он включён) спросит, разрешить ли входящие подключения, — разрешите.

## 5. Настройки

Все настройки лежат в `config/appsettings.json` внутри папки сервера:

| Система | Где файл после установки службой |
|---|---|
| Windows | `C:\Program Files\Golether Server\config\appsettings.json` |
| Linux | `/opt/golether-server/config/appsettings.json` |
| macOS | `/usr/local/golether-server/config/appsettings.json` |

```json
{
  "Rendezvous": {
    "ListenAddress": "0.0.0.0",
    "Port": 47900,
    "EnableStun": true
  },
  "Urls": "http://127.0.0.1:47980"
}
```

| Параметр `Rendezvous:…` | По умолчанию | Что задаёт |
|---|---|---|
| `ListenAddress` | `0.0.0.0` | IP-адрес **этой машины**, на котором слушать: `0.0.0.0` — все IPv4-интерфейсы, конкретный адрес — только его, `::` — IPv6 и IPv4 |
| `Port` | `47900` | порт: TCP для встреч и тот же номер по UDP для STUN |
| `EnableStun` | `true` | отвечать ли на STUN по UDP; без него камеры и голос из разных сетей соединятся хуже |
| `MaxConnections` | `1024` | одновременно открытых соединений |
| `MaxRooms` | `1024` | одновременно идущих сеансов |
| `MaxPendingPerRoom` | `16` | подключений, ожидающих ответа одного ведущего |
| `MaxConnectionsPerMinute` | `120` | новых соединений с одного IP в минуту |
| `MaxStunPerMinute` | `600` | STUN-запросов с одного IP в минуту |
| `FirstMessageTimeout` | `00:00:10` | сколько ждать первого сообщения после подключения |
| `AnswerTimeout` | `00:00:20` | сколько ведущий может отвечать на подключение участника |
| `IdleTimeout` | `00:01:30` | сколько ведущий может молчать, прежде чем его комната освободится |

| Параметр | По умолчанию | Что задаёт |
|---|---|---|
| `Urls` | `http://127.0.0.1:47980` | адрес страницы состояния `/health`; оставьте `127.0.0.1`, чтобы она была видна только на этой машине |
| `Logging:LogLevel:Default` | `Information` | подробность журнала; `Debug` — по каждому соединению |
| `Logging:Console:FormatterOptions:TimestampFormat` | `yyyy-MM-dd HH:mm:ss.fff zzz ` | метка в начале каждой строки журнала в консоли и в файле: дата, время сервера и смещение от UTC (`2026-10-11 16:14:12.250 +07:00`). Под systemd и в «Просмотре событий» Windows время записи ставит сама система |

Любой параметр можно задать и без правки файла — переменной окружения (двойное подчёркивание вместо двоеточия) или
аргументом командной строки; они перекрывают файл:

```bash
./golether-server --Rendezvous:Port=3478                      # аргумент, любая система
Rendezvous__Port=3478 ./golether-server                        # переменная, Linux и macOS
```

```powershell
$env:Rendezvous__Port = '3478'; .\golether-server.exe          # переменная, Windows
```

**После правки `config/appsettings.json` перезапустите службу** ([раздел 8](#8-управление-службой)). Если настройка
неверна, сервер не запустится и перечислит ошибки (в консоли или в журнале службы).

## 6. Роутер и брандмауэр

Снаружи должны быть доступны **оба** протокола на порту сервера.

**Роутер.** Если белый IP у роутера, а сервер стоит за ним, пробросьте на локальный адрес сервера:

| Внешний порт | Протокол | Куда |
|---|---|---|
| 47900 | TCP | `<локальный IP сервера>:47900` |
| 47900 | UDP | `<локальный IP сервера>:47900` |

Порт 47980 наружу не пробрасывайте. Облачным серверам (VPS) откройте те же порты в группе безопасности / сетевом
экране панели провайдера.

**Брандмауэр системы:**

| Система | Команды |
|---|---|
| Windows | установщик делает это сам; вручную: `New-NetFirewallRule -DisplayName 'Golether rendezvous server' -Direction Inbound -Program '<папка сервера>\golether-server.exe' -Action Allow` |
| Linux, ufw | `sudo ufw allow 47900/tcp && sudo ufw allow 47900/udp` (при включённом ufw это делает `install-service.sh`) |
| Linux, firewalld | `sudo firewall-cmd --permanent --add-port=47900/tcp --add-port=47900/udp && sudo firewall-cmd --reload` |
| Linux, iptables | `sudo iptables -A INPUT -p tcp --dport 47900 -j ACCEPT && sudo iptables -A INPUT -p udp --dport 47900 -j ACCEPT` |
| macOS | «Системные настройки → Сеть → Брандмауэр → Параметры»: разрешите входящие для `golether-server` (если брандмауэр включён) |

## 7. Что сообщить ведущим

Ведущие выбирают **«Свой сервер»** в переключателе «Гости из других сетей» на карточке «Показать фильм» в Golether и вписывают адрес сервера в появившееся поле, в виде
`адрес:порт`. Участникам ничего сообщать не нужно — адрес приходит им в ссылке-приглашении.

Сообщайте адрес, по которому сервер виден **из интернета**, а не `ListenAddress`:

| Где стоит сервер | Что вписывать ведущим |
|---|---|
| VPS или машина с белым IP на интерфейсе | этот IP (или доменное имя): `203.0.113.7:47900` |
| Дома за роутером с пробросом | внешний IP роутера, **не** `192.168.x.x`: `198.51.100.20:47900` |
| Порт изменён | новый порт: `203.0.113.7:3478` |

Если внешний IP роутера меняется, заведите для него динамическое DNS-имя и сообщите его.

## 8. Управление службой

| Действие | Windows (PowerShell от администратора) | Linux | macOS |
|---|---|---|---|
| Состояние | `Get-Service GoletherServer` | `systemctl status golether-server` | `sudo launchctl print system/org.golether.server` |
| Запустить | `Start-Service GoletherServer` | `sudo systemctl start golether-server` | `sudo launchctl kickstart system/org.golether.server` |
| Остановить | `Stop-Service GoletherServer` | `sudo systemctl stop golether-server` | `sudo launchctl bootout system/org.golether.server` |
| Перезапустить | `Restart-Service GoletherServer` | `sudo systemctl restart golether-server` | `sudo launchctl kickstart -k system/org.golether.server` |
| Журнал | «Просмотр событий → Журналы Windows → Приложение», источник `golether-server` | `journalctl -u golether-server -f` | `tail -f /Library/Logs/golether-server.log` |

После остановки через `bootout` на macOS служба запускается снова командой
`sudo launchctl bootstrap system /Library/LaunchDaemons/org.golether.server.plist` (или перезагрузкой).

## 9. Проверка работы

**На самой машине** — страница состояния:

```bash
curl http://127.0.0.1:47980/health                               # Linux, macOS
```

```powershell
Invoke-RestMethod http://127.0.0.1:47980/health                   # Windows
```

```json
{ "status": "ok", "version": "0.2.0", "protocol": 1, "uptimeSeconds": 3600,
  "rooms": 2, "connections": 3, "meetingsRequested": 14, "meetingsIntroduced": 13,
  "refused": 0, "stunAnswered": 211 }
```

| Поле | Смысл |
|---|---|
| `rooms` | идущие сеансы с этим сервером |
| `connections` | открытые соединения |
| `meetingsRequested` / `meetingsIntroduced` | сколько подключений попросили участники / скольким сторонам сервер передал адреса друг друга |
| `refused` | отказы по лимитам |
| `stunAnswered` | ответы на STUN (растёт, пока идут сеансы с камерами) |

**Снаружи** — с другой машины в другой сети (например, с телефона через мобильный интернет и ноутбука):

```bash
nc -vz 203.0.113.7 47900                                         # Linux, macOS: TCP-порт открыт?
```

```powershell
Test-NetConnection 203.0.113.7 -Port 47900                        # Windows: TcpTestSucceeded : True
```

UDP проверяется STUN-клиентом, например `stunclient 203.0.113.7 47900` (пакет `stuntman-client` в Linux).
Итоговая проверка — ведущий указывает сервер, создаёт сеанс, и в ленте событий Golether появляется «Сервер
рукопожатий … на связи».

## 10. Обновление

| Система | Как обновить |
|---|---|
| Windows | запустите установщик новой версии: он остановит службу, заменит файлы и снова её запустит; `config\appsettings.json` сохранится |
| Windows, zip | остановите службу, замените всё, кроме папки `config`, запустите службу |
| Linux, macOS | распакуйте новую версию и снова выполните `sudo ./service/install-service.sh`; `config/appsettings.json` сохранится |

Разные версии сервера и приложения совместимы, пока совпадает версия протокола (поле `protocol` в `/health`).

## 11. Удаление

| Система | Как удалить |
|---|---|
| Windows | «Параметры → Приложения → Golether Server → Удалить»: служба и правило брандмауэра удаляются |
| Windows, zip | `Stop-Service GoletherServer; sc.exe delete GoletherServer; Remove-NetFirewallRule -DisplayName 'Golether rendezvous server'`, затем удалите папку |
| Linux, macOS | `sudo ./service/install-service.sh uninstall` из папки пакета или из установленной папки |

Не забудьте закрыть проброс порта на роутере.

## 12. Безопасность

- **Сервер не видит сеансов.** Всё, что идёт между ведущим и участниками, зашифровано между их устройствами; сервер
  знает только IP-адреса, открытые ключи ведущих и время подключений. Подменить ведущего сервер не может: участник
  проверяет ключ ведущего из приглашения.
- **Комнату нельзя перехватить:** она закреплена за ключом устройства ведущего, регистрация подписана.
- **Минимальные права.** Службе Linux и macOS права root не нужны (временный пользователь / `nobody`); на Windows
  служба работает от системной учётной записи, как большинство служб.
- **Лимиты** на число соединений, комнат и частоту запросов с одного IP защищают от перегрузки. При атаке
  уменьшите `MaxConnectionsPerMinute` и `MaxStunPerMinute`.
- **Страница `/health`** не содержит адресов и имён, но всё равно держите её на `127.0.0.1`.
- Сервер не хранит ничего на диске, кроме журнала. Резервное копирование нужно только для папки `config`.
- Обновляйте сервер вместе с приложением Golether.

## 13. Неполадки

| Что видно | Что проверить |
|---|---|
| Служба не запускается | журнал службы ([раздел 8](#8-управление-службой)): неверная настройка или «Не удаётся слушать …» — порт занят другой программой (`netstat -ano \| findstr 47900` на Windows, `sudo ss -lntup \| grep 47900` на Linux, `sudo lsof -i :47900` на macOS) |
| У ведущего «Сервер рукопожатий … недоступен» | служба запущена; `/health` отвечает; TCP-порт проброшен и открыт ([раздел 9](#9-проверка-работы) — проверка снаружи); ведущему сообщён внешний адрес, а не локальный |
| У участника «Ведущего нет на сервере рукопожатий» | сеанс ещё идёт; у ведущего в ленте было «на связи»; `rooms` в `/health` больше нуля |
| «Роутеры не пропустили прямое соединение» | сервер своё сделал (`meetingsIntroduced` растёт), но сеть одной из сторон не допускает прямых соединений (симметричный NAT, часто у мобильных операторов). Это не лечится на сервере: нужен туннель AmneziaWG или проброс порта у ведущего |
| Фильм идёт, камер нет | UDP-порт проброшен и открыт; `EnableStun` = `true`; `stunAnswered` растёт |
| `refused` быстро растёт | кто-то упирается в лимиты: много участников за одним IP — поднимите `MaxConnectionsPerMinute`; подозрительная активность — посмотрите журнал с уровнем `Debug` |
| macOS: «программу нельзя открыть» | в корне папки сервера: `xattr -dr com.apple.quarantine .` и `codesign --force --sign - golether-server bin/golether-server` |
| Linux: `Permission denied` при запуске | в корне папки сервера: `chmod +x golether-server bin/golether-server service/install-service.sh` (если архив распаковывали на Windows и переносили) |
