# Golether — правила разработки

Golether — открытое (GPL-3.0-or-later) кроссплатформенное десктопное приложение для синхронного совместного
просмотра видео с веб-камерами. Проектная документация: [Docs/Architecture.md](Docs/Architecture.md).

## Общие правила

- Последние .NET и C# (сейчас .NET 10, `LangVersion=latest`), общие настройки — в `Directory.Build.props`,
  версии пакетов — централизованно в `Directory.Packages.props`.
- Каждый тип, метод, свойство, поле, конструктор и структура данных снабжается понятным XML-комментарием
  (включая `private` и тесты). Отсутствие комментария у публичного члена — ошибка сборки (CS1591).
- Только свободные зависимости, совместимые с GPL-3.0-or-later. Не добавлять пакеты без необходимости.
- Доменная логика не зависит от UI, хостинга и инфраструктуры. Интерфейсы, внедрение зависимостей,
  маленькие сервисы.
- Внешние команды, пути, конфигурации и всё, что пришло по сети, — недоверенные данные: проверять и
  завершаться понятной диагностикой.
- Операции, связанные с безопасностью, — явные, ограниченные и проверяемые.
- Время — через `TimeProvider` или `IMonotonicClock`, чтобы тесты были детерминированными.
- Критичная логика покрывается модульными и интеграционными тестами; внешние зависимости (процессы, файлы,
  сеть, БД, плеер) подменяются заглушками.

## Структура

```
Sources/
  Apps/          приложения (Golether.UI)
  Core/          ядро, данные и миграции
  Database/      консольный мигратор БД
  Media/         плеер (libmpv), раздача файла, камеры и голос
  Security/      ключи устройства, приглашения, допуск
  Session/       сборка сеанса ведущего и участника
  Sync/          протокол и синхронизация воспроизведения
  Transports/    сетевые транспорты
  Tunnels/       туннели AmneziaWG
Tests/           тестовые проекты (<Проект>.Tests)
Docs/            документация
Scripts/         упаковка и вспомогательные скрипты
```

Новый проект добавляется в `Golether.slnx` в папку решения, повторяющую путь на диске.

## Базы данных

SQLite, схема — только миграциями FluentMigrator (SQL-скрипты в `Golether.Core.Data.Migrations.SQLite/Scripts`),
доступ к данным — EF Core. `EnsureCreated` и миграции EF Core не используются.
